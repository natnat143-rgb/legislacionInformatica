# legislacionInformatica
3er Semestre

**UNIDAD 1**

Tarea 1.1

En esta materia de Legislación Informática quiero aprender cómo las leyes y reglas se relacionan con la inteligencia artificial, porque sé que no todo es programar y ya. Me interesa entender qué responsabilidades tenemos como futuros ingenieros, cómo cuidar la privacidad de las personas y qué dilemas éticos pueden aparecer cuando usamos IA. Más que memorizar leyes, lo que busco es reflexionar sobre el impacto que tiene la tecnología en la sociedad y cómo puedo aplicar lo que aprenda para ser una profesional responsable y consciente.
